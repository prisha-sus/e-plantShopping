# e-plantShopping

**e-plantShopping** is an online plant shopping application designed to provide plant lovers with a seamless browsing and e-commerce experience. Users can explore a curated selection of indoor and outdoor plants, view details, manage their shopping cart dynamically, and proceed through checkout.

---

## 🌿 Project Features

- **Plant Catalog:** Browse categorized plants (such as Air Purifying, Aromatic, and Medicinal) complete with images, pricing, and descriptions.
- **Dynamic Shopping Cart:** 
  - Real-time updates for cart item counts and subtotal calculations.
  - Adjust item quantities (increment/decrement) or remove items directly from the cart.
  - Quick action buttons to add items directly from the product catalog.
- **Navigation:** Easy page transitions between the landing landing page, plant listings, and cart summary view.
- **Responsive UI:** Clean, mobile-friendly interface optimized for all device sizes.

---

## 🛠 Tech Stack

- **Frontend Framework:** React.js
- **State Management:** Redux Toolkit / React Redux
- **Styling:** CSS3 / HTML5
- **Version Control:** Git & GitHub
